# M10 Web 门户（统一 webServer）ADR

- 状态：已定
- 日期：2026-08-20
- 背景 ADR：`2026-08-20-m7-web-search.md`（web 接缝）、`2026-08-18-m4-kb-architecture.md`（KB）
- 关联：路线图候选段（`../Agent.md` §4 候选，用户 2026-08-20 二次拍板：**Web 门户整体先行、KB 全量后补**）

## 背景

Agent 能力（M1–M9 + 评测接缝 + 模式预设/四缺口）已完整，但唯一的交互面仍是 **REPL**。dsh 提供 web 门户（会话/事件浏览、工具卡片、settings），本项目一直以 REPL 先磨循环（M1 `design.md:19` 的历史决策）。用户 2026-08-20 拍板翻转历史决策，目标是一个**个人工作台门户**：dsh 式会话/事件入口 + 知识库管理 + dashboard 工作台。

关键澄清（用户问询）：**dsh 式 web 入口不单独做**——M10 是一个统一门户，一个 webServer 承载全部功能面（会话/事件入口、KB 管理台、dashboard），共享同一 HTTP 服务/认证/前端。用户二次拍板：**统一门户整体先行，KB 管理台先空壳，KB 全量后挂**（M10a 基础设施与 dsh 式入口零 KB 依赖）。

## 决策（D-WEB-1 ~ D-WEB-7）

### D-WEB-1 统一门户 = 单个 webServer（net/http，零新依赖）
一个 `internal/webserver` 接缝，Go 标准库 `net/http` 起一个 HTTP 服务，**多功能面 = 多路由**：
- `/` 静态页面（vanilla JS 前端）
- `/api/sessions`、`/api/sessions/{id}/events` —— **dsh 式会话/事件浏览入口**
- `/api/stats/*` —— dashboard 统计
- `/api/kb/*` —— KB 管理台路由（**M10b 先空壳**：返回占位/`501`，KB 全量后挂真实实现）

不引入任何 HTTP 框架/路由库/前端构建工具（零新依赖，纪律 5）。Go 1.22+ `http.ServeMux` 方法+路径匹配足够。

### D-WEB-2 认证 = bearer token（SHA-256 摘要，恒时比对）
- config `web_server.token`：用户设置明文 token；进程内只存 `sha256(token)` 摘要（与 dsh-knowledge 一致，明文永不在内存/日志驻留）。
- 每个请求校验 `Authorization: Bearer <token>`：对摘要做恒时比较（`crypto/subtle.ConstantTimeCompare`）；无/错 token → `401`。
- 纯 bearer header，无 cookie/session/CSRF（无状态 API，静态前端 fetch 携带 header）。

### D-WEB-3 前端 = vanilla JS 静态文件（零新依赖，无构建）
- 静态文件目录（`webserver/static/`）：`index.html` + `app.js` + `style.css`（可拆模块），**纯原生 fetch + DOM**。
- 借鉴 dsh-knowledge `web/` 功能面（三栏/条目视图心智）+ dsh 门户心智（会话列表/事件流/工具卡片），不引入 React/Vite/打包器。
- 单页应用式导航（hash 路由 `#/sessions`、`#/dashboard`、`#/kb`），一个 `index.html`。

### D-WEB-4 数据 API = 只读浏览（会话/事件/统计）
- 数据源：`internal/store.Store`（`ListSessions`/`LoadSession`）+ `internal/session` 事件模型。
- **只读**：M10a 提供会话列表、单会话事件流（含事件类型/时间/摘要）、dashboard 统计聚合；**不经 web 写入会话**（REPL 仍是唯一交互面，D4/D5 循环结构不动；web 入口未来可扩展消息发送，本期不做）。
- API 载荷 = 最小 owned 数据（会话元数据、事件 `{seq,type,time,summary}`），事件 data 字段只传安全摘要/类型，**不传完整日志正文**（防泄露 + 防超大载荷；借鉴 eval/run 事件"只记元数据"心智）。

### D-WEB-5 dashboard 统计 = Store 聚合（只读）
- `/api/stats`：会话总数、事件总数、事件类型分布、工具调用计数、最近活动时间——从 `ListSessions` + 按需 `LoadSession` 聚合，内存计算，无新增存储。
- dashboard 页面用 `fetch` 拉 JSON + 原生渲染（列表/简单柱状；不引入图表库，纯 DOM/CSS，诚实有限可视化）。

### D-WEB-6 分段派发（KB 管理台空壳后挂）
按依赖拆三段，逐段派发/验收：
- **M10a** webServer 基础设施：`internal/webserver`（ServeMux 路由 + 认证中间件 + 静态托管）+ config（默认关 D10）+ `/api/sessions`、`/api/sessions/{id}/events`（dsh 式入口）+ `/` 静态页（会话列表 + 事件流前端）+ cmd/pa 接线（`/web` 启动命令 or 启动即监听？——决策：`web_server.enabled=true` 时随进程启动监听，不新增 REPL 命令；printHelp 显示状态）。
- **M10c** dashboard 工作台：`/api/stats` + dashboard 页面（会话/事件/工具统计 + 工作台入口链接）。
- **M10b** KB 管理台（**空壳**）：`/api/kb/*` 路由返回 `501 not implemented` 占位 + `#/kb` 页面占位（"KB 全量后挂"）；不实现任何 KB 数据逻辑。
- KB 全量（内容层）后：M10b 路由从占位换成真实 KB API/页面（单独里程碑）。

### D-WEB-7 安全与配置
- config `web_server: {enabled: false, addr: "127.0.0.1:8080", token: ""}`（默认关 D10：enabled=false 不监听；token 空则启动报错 fail-closed，防裸奔）。
- 默认 `127.0.0.1`（本地个人门户，不默认暴露局域网）；addr 可配。
- 不落日志 secrets（token 永不出现在事件/日志）。
- 静态文件嵌入：用 Go `embed`（`//go:embed static`）打包进二进制（零外部资源依赖，单二进制部署）。

## 理由

1. **统一门户而非多服务**：一个 webServer + 多路由，共享认证/静态托管/前端心智，运维与依赖面最小（零新依赖目标下尤其重要）。
2. **只读先行的理由**：会话/事件浏览 + 统计只依赖已有 Store/session，零新存储、零循环改动，能最快交付"看得见 Agent"的入口；写入/交互面（发送消息）涉及循环与并发边界，本期不做（D4/D5 保持）。
3. **vanilla JS**：无构建工具、无 node_modules、`go:embed` 单二进制分发——与全项目"零新依赖、CGO-free"纪律一致，也符合 Windows 无工具链环境。
4. **KB 空壳后挂**：M10b 的路由/页面骨架先立（`#/kb` 可点），数据层等 KB 全量（内容层定稿条目/挂载/回写结构）后填——避免管理台随 KB 数据结构未定稿而返工（用户二次拍板）。
5. **bearer + SHA-256 摘要**：dsh-knowledge 同款心智，无状态、无 cookie、恒时比对，个人门户够用且不引依赖。

## 后果

- **好处**：Agent 首次获得可视化门户（会话/事件/dashboard）；统一 webServer 后续可承载 KB 管理台、设置等更多功能面；`go:embed` 单二进制零部署成本。
- **代价/限制**：本期只读（无 web 发消息）；dashboard 可视化诚实有限（无图表库）；KB 管理台先空壳（要等 KB 全量）；默认仅 localhost（要局域网需显式配 addr，暴露面自理）。
- **放弃的方案**：① 分开的 KB web 服务 + Agent web 服务（两套认证/托管，违背统一门户；② 引入 React/Vite/前端构建（违背零依赖、引入 node 工具链）；③ 本期做 web 发消息/交互（触碰循环并发边界，D4/D5 不可动摇）；④ 默认监听 0.0.0.0（个人门户默认本地，显式才暴露）。
